# FluentHome

Лаунчер для Android TV / Google TV и приложение-компаньон **FluentHome Setup** для Android-телефона.

## Скачать

- [FluentHome Setup для телефона](https://github.com/cepjjj-cmd/FluentHome/releases/latest/download/FluentHome-Setup.apk) — Android 9 и новее.
- [FluentHome для телевизора](https://github.com/cepjjj-cmd/FluentHome/releases/latest/download/FluentHome.apk) — Android TV / Google TV 11 и новее.
- [Последний релиз и список изменений](https://github.com/cepjjj-cmd/FluentHome/releases/latest).

## Установить или обновить

1. Установите FluentHome Setup на телефон.
2. Подключите телефон и ТВ к одной локальной сети. Включите сетевую отладку на телевизоре и подключитесь из Companion. На некоторых моделях понадобится сопряжение по коду.
3. Откройте **Управление**. Companion автоматически проверяет GitHub; для повторной проверки есть кнопка **Проверить обновления**.
4. Нажмите **Скачать и обновить**. Настройки FluentHome и порядок плиток сохранятся.

Обновление выполняется только после вашего подтверждения и на подключённом телевизоре. Для остальных ТВ повторите подключение. Телефон не обязан быть подключён к GitHub-аккаунту.

Без интернета можно установить APK, встроенный в Companion. Если на ТВ уже более новая версия, Companion не заменит её старой. Для следующих обновлений FluentHome переустанавливать сам Companion не требуется.

После настройки отладку можно выключить. Перед следующим обновлением включите её и подключитесь снова; порт беспроводной отладки может измениться.

## Обновление прямо на ТВ

Начиная с FluentHome 0.6.22, лаунчер проверяет GitHub самостоятельно. Когда есть более новая совместимая версия, внизу настроек появляется **Доступно обновление**. По нажатию открывается системное окно со списком изменений, затем скачивание и стандартный установщик Android.

В FluentHome 0.6.23 меню настроек лаунчера открывается удержанием кнопки **Settings**. Короткое нажатие открывает системные настройки Android. Такая же логика действует для Wi-Fi и ночного режима: нажатие выполняет действие, удержание открывает дополнительное меню.

При первом таком обновлении может потребоваться разрешить FluentHome установку приложений. Подтверждение установки выполняется в системном окне. Если прошивка не предоставляет этот способ, используйте Companion.

На актуальной версии дополнительный пункт в настройках скрыт. Никакие обновления не устанавливаются без вашего действия.

## Копия настроек

Нужны FluentHome **0.6.24+** на ТВ и FluentHome Setup **0.1.9+** на телефоне. Подключитесь к ТВ и откройте **Управление → Настройки лаунчера**.

- **Создать копию настроек** сохраняет док, порядок приложений, анимации, расширенные эффекты и силу затемнения на телефоне.
- **Сохранить копию в файл** создаёт переносимый JSON. На другом телефоне или ТВ используйте **Открыть копию из файла**, затем **Восстановить настройки**.
- Перед восстановлением текущее состояние ТВ сохраняется отдельно. Его можно вернуть кнопкой **Вернуть настройки до восстановления**.

Отсутствующие на другом ТВ приложения пропускаются; если нужно, док дополняется установленными приложениями до минимального числа плиток. Сам ночной режим не включается, восстанавливается только сила затемнения. Разрешения выдаются на каждом ТВ отдельно.

Копия настроек лаунчера отличается от копии очистки: она не меняет состояния системных приложений и назначение главного экрана. Для передачи используется уже разрешённое ADB-подключение Companion; учётные данные ADB, медиакэш и история просмотра в копию не входят. Обычные приложения на ТВ не могут читать или восстанавливать настройки через этот интерфейс.

## SmartTube и фон

Начиная с 0.6.25, блок «Продолжить просмотр» может показывать последний ролик из канала истории, который сам SmartTube публикует Android TV. Запись Watch Next имеет приоритет. Открытие направлено только в SmartTube; данные официального YouTube не подставляются. История может включать досмотренный ролик, а восстановлением позиции управляет SmartTube. Если канал истории не опубликован или отключён в SmartTube, карточки не будет.

Для приложений без качественной обложки доступен медленный нативный mesh-градиент в фирменных цветах, внутри прежней маски. Он движется при включённых **Анимация** и **Расширенные эффекты**; при отключении остаётся статичный фон.

В версии **0.6.26** градиент переведён на заранее подготовленные неизменяемые кадры: они рассчитываются в фоне, при показе смешиваются два изображения. Во время навигации движение фона приостанавливается, чтобы отдать приоритет переключению плиток. Для палитры используются два оттенка из иконки либо основной цвет и сочетающийся соседний оттенок.

## Выпуск новой версии

После сборки подписанных APK:

```sh
python3 scripts/publish.py \
  --launcher /path/to/FluentHome.apk \
  --companion /path/to/FluentHome-Setup.apk \
  --notes /path/to/release-notes.md \
  --sdk /path/to/Android/sdk \
  --publish
```

Нужны Python 3, JDK, Android SDK build-tools и GitHub CLI с авторизацией владельца репозитория. Без `--publish` скрипт только готовит файлы локально. Он проверяет подписи APK, получает номера версий из APK и формирует `launcher.json` и `SHA256SUMS`. При публикации сначала создаётся черновик с файлами, затем релиз становится доступным для Companion.

Для нового лаунчера можно передать прежний APK Companion с поддержкой онлайн-обновлений. Сохраняйте идентификаторы приложений и исходные ключи подписи. Приватные ключи и токены в этот репозиторий не загружаются.

Репозиторий содержит готовые сборки и инструменты публикации. Лицензии используемых компонентов включены в APK; сведения также доступны в [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).
